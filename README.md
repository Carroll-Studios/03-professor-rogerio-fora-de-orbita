<br/>

O **projeto-livre** da Carroll Studios é um jogo educativo espacial. O professor Rogério manda uma aluna para o espaço, a nave dela se quebra, e é preciso reconstruí-la respondendo perguntas.

<img src="./resources/images/star-divider-2.svg" width="100%" alt="" />

<div align="center"><img src="https://img.shields.io/badge/🎯_Objetivos-EC4899?style=for-the-badge&logoColor=white" alt="Objetivos" /></div>

<br/>

- Contar essa história por meio de cenas com personagens e diálogos.
- Reconstruir a nave respondendo perguntas corretamente.
- Aplicar os conceitos de Programação Orientada a Objetos trabalhados no semestre.
